## Evaluated visual source

[Kenney UI Pack](https://kenney.nl/assets/ui-pack) is CC0 and suitable for prototyping. It is not imported into the game because its generic visual language conflicts with Dungeon Union’s hand-painted, screen-print presentation. The pack remains a vetted option for future accessibility controls or developer tooling.
